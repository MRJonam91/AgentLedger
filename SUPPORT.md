# Support / Supporto

EN: Use [GitHub issues](https://github.com/MRJonam91/AgentLedger/issues) for installation and usage questions. Include version, OS, command name, fixed error code and synthetic input. For `unsupported_schema` or `chain_invalid`, stop writing, preserve a private copy and compare a separately saved checkpoint; do not edit hashes to force a pass. Unknown/pending calls can have provider charges: inspect your provider account before retrying. Rate/model mismatch requires an exact returned-model rate card for **new** records; imports already stored are immutable. No SLA or paid support contract is included.

IT: Usa le [issue GitHub](https://github.com/MRJonam91/AgentLedger/issues) per installazione/uso. Includi versione, OS, nome comando, codice errore fisso e input sintetico. Per `unsupported_schema` o `chain_invalid` interrompi le scritture, conserva una copia privata e confronta un checkpoint separato; non cambiare gli hash per forzare l'esito. Chiamate ignote/pendenti possono avere addebiti: verifica l'account provider prima di riprovare. Se modello/tariffe non coincidono serve una scheda per il modello esatto sui **nuovi** eventi; gli import già registrati sono immutabili. Nessuno SLA o contratto di supporto a pagamento incluso.
