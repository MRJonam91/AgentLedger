# AgentLedger 1.0 Implementation Plan

> Execute inline with executing-plans; request an independent read-only review before publication.

**Goal:** Complete the backward-compatible local CLI and publish stable 1.0.
**Architecture:** Share preflight validation and exclusive export primitives, keep verification in the existing ledger boundary, preserve schema and source accounting.
**Tech stack:** Python 3.11+ standard library; unittest/mypy/build tooling for development only.
**Spec:** `docs/superpowers/specs/2026-10-24-v1-design.md`.

## Global constraints

No raw content/credentials in stored events or errors; default deny before network effects. No v1 schema/hash rewriting. Core under 1,500 physical lines, no runtime dependencies, EN/IT docs, GPL-3.0-or-later. Keep local operational material outside the distribution contract. No paid calls or implied invoice/security certification.

## Review focus

- Existing output/ledger path: preserve exact bytes on initialization/export failure.
- Invalid prompt/model/output count: no new database or provider contact.
- Concurrent new collectors: serialize schema initialization and dedupe complete batches.
- Actual HTTP redirect/malformed payload: one attempt, strict decode, no automatic forwarding.
- Release package: compare contents with the tested commit; preserve license and exclude local material.
