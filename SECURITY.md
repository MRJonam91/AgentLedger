# Security / Sicurezza

EN: The latest 1.x stable release is the supported line; alpha/beta v1 data remains readable without migration. The application is not a security boundary. For a suspected vulnerability, use [GitHub private vulnerability reporting](https://github.com/MRJonam91/AgentLedger/security/advisories/new); never post keys, personal data or private ledgers in public issues. Request coordinated disclosure, normally allowing up to 90 days for investigation and a fix; shorter timelines may be needed for active exploitation. Response times are best effort. The threat model and skipped verification checks are documented under docs/.

IT: L'ultima release stabile 1.x è supportata; i dati alfa/beta v1 restano leggibili senza migrazione. L'applicazione non è un confine di sicurezza. Per vulnerabilità sospette usa le [segnalazioni private GitHub](https://github.com/MRJonam91/AgentLedger/security/advisories/new); non pubblicare chiavi, dati personali o registri privati nelle issue. Si richiede disclosure coordinata, normalmente fino a 90 giorni per indagine/correzione; sfruttamenti attivi possono richiedere tempi inferiori. Tempi di risposta senza garanzia. Modello di minaccia e verifiche mancanti sono in docs/.
